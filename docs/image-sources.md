# 진료 콘텐츠 이미지 출처

이번 작업에서 외부 사진·아이콘·의료 일러스트레이션은 사용하지 않았다.

| 설명도식 | 위치 | 제작 방식 | 사용 조건 |
| --- | --- | --- | --- |
| 임플란트 연결 구조 | treatment-content.tsx / ImplantDiagram | 프로젝트 내 자체 SVG | 실제 제품 비율·연결 방식과 다른 개념도. 의료진 검토 필요 |
| 일반 브릿지와 메릴랜드 브릿지 | treatment-content.tsx / BridgeDiagram | 프로젝트 내 자체 SVG | 삭제량이나 치아 형태를 표현하지 않는 구조 개념도. 의료진 검토 필요 |
| 디지털 가이드, VPT, 레진 빌드업, STM 등 | TreatmentFlow | semantic HTML/CSS | 일반적인 논리 흐름. 결과 이미지 아님 |
| 치간이개 선택지 | DiastemaOptions | semantic HTML/CSS | 조건별 선택지. 자동 진단 아님 |

제작·기록일: 2026-09-30. 외부 라이선스 확인이 필요한 새 production 이미지 없음. 기존 원장 사진과 기존 이미지 파일은 수정하지 않았다.
