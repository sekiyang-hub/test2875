# 진료 콘텐츠 최종 검토

기존 병원 기본정보, 관리자 상태 설정, 예약·전화·지도 링크와 외국어 안내를 유지했다. 진료 콘텐츠는 일반적인 환자 교육 정보이며 실제 본원 제공 여부를 확정하지 않는다.

## 의료진이 확인할 사항
1. 모든 항목의 실제 본원 진료범위. 특히 재식립·재수술, 픽스처·스크류 파절 수리, 상악동 수술, 외과적 치주치료, 재근관치료, VPT, 교정과 턱관절 치료.
2. VPT의 선택 기준, 치수 처치 범위 및 사용 재료에 관한 설명.
3. 무삭제·최소삭제 라미네이트, 메릴랜드 브릿지와 지르코니아 인레이·온레이의 적용 범위.
4. STM의 정확한 장비·제작 단계 및 표면처리 방법. 실험실 접착강도를 장기 임상결과로 일반화하지 않는 현재 표현 유지.
5. 자체 임플란트 SVG의 연결 구조와 브릿지 도식의 설명. 날개 수와 지지 치아 형태는 증례마다 다르다는 문구 확인.
6. 발치·교정·턱관절 및 합병증 관리 시 실제 의뢰 기준과 관리 지침.

## 근거
src/content/treatment-guides.ts의 sources에 FDA, NIDCR, AAE, ITI, ADA MouthHealthy, Leeds Teaching Hospitals 및 STM 실험실 연구 자료를 연결했다. 직접 인용, 성공률 수치, 제조사 접착강도 홍보 수치, 결과 보장 문구는 사용하지 않았다. 의료진이 작성 또는 승인했다고 표시하지 않았다.

## 이미지와 번역
새 외부 이미지나 실제 치료 전후 사례는 추가하지 않았다. 턱관절 해부학 도식과 추가 단면 이미지는 visual-assets-needed.md 참조. 이번 작업은 한국어 진료 콘텐츠 개편이며 기존 외국어 안내는 유지했다. 확장된 의료 콘텐츠의 외국어 번역은 별도 의료 검토가 필요하다.
