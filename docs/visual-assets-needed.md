# 추가 제작이 필요한 설명 이미지

현재 진료 콘텐츠는 자체 제작 SVG 2종과 HTML/CSS 흐름도로 설명한다. 외부 사진이나 치료 전후 사진은 추가하지 않았다. 흐름도는 검사·치료의 논리적인 순서이며 실제 해부학 또는 치료 결과를 나타내지 않는다.

## 턱관절 위치와 하악 운동
- 페이지: /treatments/temporomandibular-disorders/
- 목적: 귀 앞쪽 턱관절과 저작근, 개구 운동의 관계 설명
- 구조: 측면 두개골의 관절와, 하악과두 및 하악 위치. 개구 시 회전·활주의 단순화된 방향. 턱관절 소리의 원인을 단정하는 병변은 넣지 않는다.
- 구도: 좌측 얼굴 측면, 관절 부분 확대를 오른쪽에 배치. 모바일에서는 확대도가 아래에 배치되는 2개 독립 이미지 권장.
- 비율: 전체 4:3, 확대 1:1. 모바일 본문 너비, 데스크톱 최대 680px.
- 정확성: 치과의사의 해부학·운동 방향 검토 필수. 그림만으로 진단하거나 특정 치료가 필요하다고 표현하지 않는다.
- 권장 ALT: 턱관절의 위치와 입을 벌릴 때 하악의 회전·활주 운동을 설명하는 개념도.

## 필요 시 추가할 치아 단면과 VPT 도식
- 페이지: /treatments/vital-pulp-therapy/, /treatments/resin-build-up/
- 목적: 현재 HTML 흐름도에 더하여 치질·치수와 수복 재료 위치를 설명.
- 구조: 법랑질, 상아질, 치수 경계 및 치료 범위별 재료 위치를 구분. 모든 VPT가 동일한 치수 절제 범위라는 인상을 주지 않는다.
- 구도: 3:2 측면 단면, 모바일 본문 안에서는 1:1 개별 단계로 분리 가능.
- 정확성: 노출 부위·치수 처치 범위·MTA 위치·최종 수복의 임상적 타당성 검토 후 사용.
- 권장 ALT: 치수 상태에 따라 처치 범위를 결정하고 MTA 적용 후 수복하는 생활치수치료 개념도.

## 실제 임상사진 확장
진료 데이터의 sections에 새 도식·사진을 연결할 수 있고, 상세 렌더러의 figure 위치에 기존 Next Image를 재사용할 수 있다. 실제 환자 사진은 공개 사용 동의, 비식별화, 의료진 설명 및 파일별 권한 확인 후 추가한다. 스톡사진을 본원 치료사례로 사용하지 않는다.
